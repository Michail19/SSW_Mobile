# Simple Schedule Work (Мобильное приложение)

Мобильное приложение для просмотра расписания рабочих смен через WebView. Гибридное решение, объединяющее веб-интерфейс и нативную оболочку Android.

---

## Особенности

- **WebView-интеграция**: Отображение веб-приложения внутри нативного интерфейса.
- **Резервный режим**: При сбое WebView ссылка открывается во внешнем браузере.
- **Навигация назад**: Поддержка истории внутри WebView.
- **Простая архитектура**: Минималистичный код с обработкой ошибок.

---

## Требования

- Android 5.0 (API 21) или выше.
- Интернет-соединение для загрузки веб-контента.

---

## Установка и сборка

1. Клонируйте репозиторий:

```bash
   git clone https://github.com/Michail19/SSW_Mobile.git
```

2. Откройте проект в Android Studio.
3. Измените URL (опционально):

** Отредактируйте поле url в классе MainActivity.

4. Соберите APK:

** Build > Generate Signed Bundle / APK.


Приложение можно установить на Android устройство по [ссылке](https://drive.google.com/file/d/1fa9SxW8r3W_zkOBOi61vftugMi4XJt3o/view?usp=drive_link).

---

## Запуск

* На физическом устройстве: включите режим разработчика и установите APK.
* В эмуляторе: запустите через Android Studio (AVD Manager).

---

## Настройка веб-контента

Приложение загружает данные с URL: [https://michail19.github.io/SimpleScheduleWork/](https://michail19.github.io/SimpleScheduleWork/).

Чтобы изменить источник:

1. Откройте `MainActivity.java`.
2. Обновите значение переменной `url`

---

## Логика работы

При запуске открывается `WebActivity` с WebView.

При критической ошибке:
* Ссылка открывается в браузере устройства.
* Пользователь видит Toast-уведомление об ошибке.
